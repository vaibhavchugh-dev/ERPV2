# ERPV2

This repository contains the ERPV2 project (Cimmple API and UI components).

Quick start

1. Restore dependencies for the .NET projects and the UI.
2. Run the API and UI according to their individual README or startup scripts.

Repository layout

- `Cimmple_API/` — backend API projects
- `Cimmple_UI/` — frontend UI

To push this repository to a remote Git host, initialize Git and add a remote:

```powershell
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <your-remote-url>
git push -u origin main
```
